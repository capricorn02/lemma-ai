# 🎙️ LEMMA — Платформа «Живых Демонстраций» (Live Demos)

Репозиторий содержит исходный код по проекту LEMMA - Лекционная МультимедиаАудитория, развивающего новые технологии и средства электронного обучения

## 📁 Структура проекта и дерево каталогов

```text
lemma-ai/
│
├── assets/              			      # Папка с общими ресурсами проекта
│

└── DemoObjectTest/                 # Отладочная песочница Живых Демонстраций
    │
    ├── index.php                   # Точка входа в , HTML5-каркас и шаблоны окон w2ui
    ├── app.js                      # Главный диспетчер интерфейса (Popup-окна Студии/Плеера)
    ├── api.php                     # Серверный контроллер (REST API, работа с LONGBLOB MySQL)
    │
    └── js/                         # Папка JavaScript-модулей (ES6 Imports)
        ├── slideA.js               # Абстрактное ядро ЖД (Математика нормирования, таймлайн)
        ├── slideRastr2d.js         # Модуль 2D Растра (Отрисовка картинок, события мыши, перо)

        ├── appGridObjects.js       # Конфигурация левого грида w2ui (Исходные заготовки)
        └── appGridScenarios.js     # Конфигурация правого грида w2ui (Записанные сценарии)
    └── modules/                         # Папка JavaScript-модулей библиотеки Демообъектов(ES6 Imports)
        ├── slideA.js               # Абстрактное ядро ЖД (Математика нормирования, таймлайн)
        ├── slideRastr2d.js         # Модуль 2D Растра (Отрисовка картинок, события мыши, перо)
        ├── slideVideo.js           # Модуль Видео-слайдов (Синхронизация маркера поверх видео)
```

## 🛠️ Технологический стек
* **Backend:** PHP 8.2+, PDO MySQL (Драйвер MySQL-8.2 в OSPanel)
* **Frontend:** JavaScript (ES6 Modules), Canvas API, w2ui 2.0 (UI-компоненты Layout, Grid, Popup)
* **База данных:** `demotest` (Таблицы `demo_objects` и `demo_commands` с поддержкой бинарных LONGBLOB)

## 🚀 Как запустить стенд локально
1. Разверните репозиторий в папку вашего хоста в Open Server (например, настройте алиас `ai` на корень проекта).
2. Импортируйте или создайте в MySQL базу данных `demotest`.
3. Запустите в браузере адрес: `http://localhost/DemoObjectTest/index.php`.
4. Для применения обновлений из чата используйте локальный инструмент: `http://localhost/Cooperation/patcher.php`.
