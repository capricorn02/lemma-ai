# Lecture Recorder LIVE (LectureRecorder): Рекордер лекций

## Назначение
Приложение предназначено для записи мм-лекции "вживую", одним кадром. В отличие от Редактора Лекциий (LectureEditor), предполагающего работу с каждой Секцией Лекции в произвольном порядке, Рекордер Лекций предполагает запись лекции "одним кадром".
Такое приложение может быть применено для быстрой записи Лекции, с последующем применениим в случае необходимости Редактора Лекций для различных правок.
Приложение также может быть полезно для того, чтобы записать лекцию, которая реально читаеся лектором для аудитории. Для этого в приложении имеется режим, аналогичный режиму Докладчика, например, в программе MS PowerPoint. В программе имеется возможность дублировать медиапоток с окна с демонстрацией в другое окно - клон, и отображать это окно на отдельном мониторе.  

## Запуск и передаваемые параметры
Предполагается что приложение не является самостоятельной точкой входа и запускается обычно из программы LecturerWP. Программа, запускающая программу LectureRecorder должна выполнить следующие действия: 
1. выполнить необходимую авторизацию лектора и выполнить соединение с БД, сохранив параметры подключения в PHP-сессии 
2. вызвать LectureRecorder, передав параметр ID со значением идентификатора сценария Мультимедиа лекции

## Работа приложения 
Запуск приложения начинается с отображения главного окна его многооконного веб-интерфейса. Главное окно всегда открывается в новом окне браузера.
В главном окне отображается информация о состоянии программы и основные инструменты работы с приложением:
- Индикатор записи показывает ведется ли в настоящее время запись лекции. Имеет графический вид: красный круг, если в данный момент ведется запись лекции, и черный квадрат в противном случае;
- Счетчик записанных секций - число, указывающее сколько секций лекции записано к настоящему моменту. Если в текущий момент идет запись очередной секции, то эта секция учитывается. В начале работы программы и до начала записи первой секции счетчик записанных секций равен нулю.
- Указатель текущего слайда - число, указывающее порядковый номер текущего слайда в сценарии, по которому пишется лекция. В начале работы программы значение указателя устанавливается в "1". После окончания записи секции, если при этом не указывается  При окончании записи секции утанавливается в екция, которая записываетсся 
- Прогрессор лекции - кнопка, нажатие на которую начинает запись следующей секции на основе слайда, следующего за текущим.
Если в момент нажатия кнопки записывается секция с порядковым номером K, основанная на слайде с порядковым номером L в текущем сценарии, то после нажатия запись секции K закончится и сразу же начнется запись секции K+1 основанной на слайде L+1
Если в момент нажатия кнопки запись не производится, то начинается запись новой секции, основанной на текущем слайде. В начале работы программмы текущим слайдом устанавливается первый слайд. - Кнопка "Стоп" останавливает запись и сохраняет записанную секцию в БД. Кнопка разрешена только если запись производится. Номер текущего слайда инкрементируется, если только текущий слайд не является последним в сценарии.
- Кнопка "Открыть содержание" открывает содержание сценария в виде выпадающего списка заголовков слайдов сценария, что позволяет выбрать текущим произвольный слайд и начать запись секции, на нем основанной.
- Кнопка "Открыть окно демо" открывает окно демонстраций в которых отображается текущий слайд и осуществляется управление им. предполагается, что окно демонстраций должно быть открыто в любом случае, однако, в связи со стандартами W3C оно не может быть открыто автоматически.

Это окно может быть размещено на втором мониоре компьютера лектора для трансляции на аудиторию, что позволяет скрыть от аудитории интерфейс приложения и другие элементы основного монитора компьютера лектора.
