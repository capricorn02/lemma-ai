# Концептуальная схема базы данных проекта ЛЕММА

## Общие правила и установки именования
1. **Имена таблиц:** Пишутся строго строчными (маленькими) буквами во множественном числе на английском языке (например: `cards`, `slides`).
2. **Имена атрибутов:** Начинаются с **Прописной (заглавной) буквы**. Если имя состоит из нескольких слов, используется `Snake_Case` с сохранением заглавных букв для каждого слова (например: `DemoType_ID`, `Order_Num`).
3. **Первичные ключи (PK):** Реализуются в виде суррогатных автоинкрементных ключей. Именуются как `Сущность_ID` в единственном числе (например: `Card_ID`, `Slide_ID`).
4. **Обязательные поля:** Большинство сущностей содержат обязательное текстовое поле `Name` типа `VARCHAR(255) NOT NULL`.

---

## Описание таблиц

### 1. Таблица `demotypes` (Типы Демо Объектов)
Описывает типы медиа-контента (графика, видео, 3D-объект, интерактивная карта и т.д.).
*   **DemoType_ID** `INTEGER PK AUTO_INCREMENT` — Первичный ключ
*   **Name** `VARCHAR(255) NOT NULL` — Название типа контента
*   **Notes** `MEDIUMTEXT` — Описание возможностей типа
*   **URL** `VARCHAR(255)` — Путь к программному модулю, обрабатывающему данный тип

### 2. Таблица `cards` (Карточки)
Базовое хранилище демонстрационных единиц.
*   **Card_ID** `INTEGER PK AUTO_INCREMENT` — Первичный ключ
*   **Name** `VARCHAR(255) NOT NULL` — Название карточки
*   **Notes** `MEDIUMTEXT` — Учебные заметки / методическое описание
*   **Demo** `LONGBLOB` — Бинарные данные демонстрации
*   **DemoType_ID** `INTEGER FK` -> `demotypes(DemoType_ID)` — Ссылка на тип контента

### 3. Таблица `folders` (Папки)
Для организации и группировки Карточек.
*   **Folder_ID** `INTEGER PK AUTO_INCREMENT` — Первичный ключ
*   **Name** `VARCHAR(255) NOT NULL` — Название папки
*   **Notes** `MEDIUMTEXT` — Описание назначения папки

### 4. Таблица `shortcuts` (Ярлыки Карточек)
Связующая таблица (Many-to-Many) для включения Карточек в Папки без дублирования данных.
*   **Card_ID** `INTEGER PK FK` -> `cards(Card_ID)` — Часть составного PK, ссылка на Карточку
*   **Folder_ID** `INTEGER PK FK` -> `folders(Folder_ID)` — Часть составного PK, ссылка на Папку

### 5. Таблица `scenarios` (Сценарии)
Подготовленные планы (презентации) для проведения лекций.
*   **Scenario_ID** `INTEGER PK AUTO_INCREMENT` — Первичный ключ
*   **Name** `VARCHAR(255) NOT NULL` — Название сценария
*   **Notes** `MEDIUMTEXT` — Описание лекционного плана

### 6. Таблица `slides` (Слайды)
Шаги, из которых состоит Сценарий. Данные копируются из Карточек.
*   **Slide_ID** `INTEGER PK AUTO_INCREMENT` — Первичный ключ
*   **Name** `VARCHAR(255) NOT NULL` — Название слайда
*   **Notes** `MEDIUMTEXT` — Текст/заметки лектора для этого шага
*   **Scenario_ID** `INTEGER FK` -> `scenarios(Scenario_ID)` — Привязка к Сценарию
*   **Order_Num** `INTEGER` — Порядковый номер слайда в сценарии
*   **Demo** `LONGBLOB` — Скопированные бинарные данные из Карточки
*   **DemoType_ID** `INTEGER FK` -> `demotypes(DemoType_ID)` — Скопированный тип контента

### 7. Таблица `lectures` (Лекции)
Записи реально проведенных лекций.
*   **Lecture_ID** `INTEGER PK AUTO_INCREMENT` — Первичный ключ
*   **Name** `VARCHAR(255) NOT NULL` — Название лекции (изначально берется из Сценария)
*   **Notes** `MEDIUMTEXT` — Описание/итоги лекции

### 8. Таблица `sections` (Разделы лекции)
Фактически показанные Слайды в процессе чтения Лекции, дополненные интерактивными командами.
*   **Section_ID** `INTEGER PK AUTO_INCREMENT` — Первичный ключ
*   **Name** `VARCHAR(255) NOT NULL` — Название раздела
*   **Notes** `MEDIUMTEXT` — Заметки раздела
*   **Lecture_ID** `INTEGER FK` -> `lectures(Lecture_ID)` — Привязка к конкретной Лекции
*   **Order_Num** `INTEGER` — Порядковый номер раздела в лекции
*   **Demo** `LONGBLOB` — Бинарные данные демонстрации
*   **DemoType_ID** `INTEGER FK` -> `demotypes(DemoType_ID)` — Тип контента
*   **Commands** `MEDIUMTEXT` — Строка JSON для записи динамических действий лектора (масштабирование, пометки, повороты объектов) синхронно с таймлайном.
*   **Video** `LONGBLOB` — Бинарные данные Видео лектора.
