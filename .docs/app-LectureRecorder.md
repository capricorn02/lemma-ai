# LectureRecorder (MML Recorder LIVE) : Рекордер мультимедиа лекций

## Назначение
Приложение предназначено для записи мультимедиа лекций "вживую", в процессе чтения лекции как единого представления. 

В отличие от Редактора мультимедиа лекций (`LectureEditor`), который предполагает работу с каждой Cекцией в произвольном порядке, `LectureRecorder` оптимизирован для непрерывной записи. Это позволяет:
* Быстро записывать лекции с возможностью последующей дополнительной правки в Редакторе мультимедиа лекций.
* Записывать реальные лекции, читаемые лектором вживую перед аудиторией. 

Для работы с аудиторией реализован аналог "режима докладчика" (как в MS PowerPoint): медиапоток из окна демонстрации дублируется в окно-клон, которое выводится на отдельный монитор/проектор.

## Порядок работы (бизнес-процесс) 
Лектор для записи мультимедиа лекции выбирает Сценарий, по которому будет записывать Лекцию (аналогично тому как докладчик выбирает презентацию для доклада) и загружает ее в LectureRecorder. Запись мультимедиа лекции состоит в последовательной записи Разделов Лекции. Каждый Раздел основывается на одом из Слайдов Сценария, а запись  Раздела состоит из видео лектора, объясняяющего материал Раздела и записи манипуляций лектора Демо-объетом Слайда, соответствующего Разделу. Выбор Слайда для записи следующего Раздела может быть выбран одним из двух способов.

Первым и наиболее часто используемым способом выбора Слайда являяется выбор следующего,  доступный если текущий Слайд не последний в Сценарии.

Второй способ используется, если необходимо выбрать другой Слайд, что делается выбором нужного слайда в списке Слайдов Сценария.

Между записями Разделов лектор может делать паузы. Вызов паузы  немедленно влечет за собой завершение записи Раздела и сохранение его в Лекции. Во время паузы никаой записи не ведется.

Когда все необходимые Разделы записаны лектор инициирует окончание записи Лекции. При этом если ведется запись Раздела, то она закачивается, все данные сохраняются в БД. после чего программа завершает свою работу.

Во время записи Раздела лектор представляет (озвучивает) учебный материал и, манипулируя Демо-объектом Слайда, синхронно иллюстрирует представление. Запись видео лектора и манипуляций его с Демо-объектом записываются и сохраняются в БД. Демо-объекты полиморфны, а инструментарий для работы с ними определяется модулем конкретного типа Демо-объекта.  

## Запуск и передаваемые параметры
Приложение не является самостоятельной точкой входа. Обычно оно запускается из родительской программы `LecturerWP`(Lecture WorkPlace) являющейсяя Рабочим местом лектора. 

Перед запуском `LectureRecorder` вызывающая программа должна:
1. Выполнить авторизацию лектора.
2. Установить соединение с БД и сохранить параметры подключения в PHP-сессии.
3. Вызвать `LectureRecorder`, передав в GET/POST запросе параметр `ID` (идентификатор Сценария мультимедиа-лекции).

## Интерфейс и работа приложения 
Приложение имеет многооконный веб-интерфейс. Главное окно всегда открывается в новом окне браузера. Оно служит пультом управления и содержит:

* **Индикатор записи:** Графический маркер статуса. Красный круг — запись ведется; черный квадрат — запись остановлена.
* **Счетчик Разделов:** Количество Разделов в Лекции на текущий момент. Если ведется запись, то записываемый Раздел учитывается в счетчике. В начале работы (до старта первой записи) значение счетчика равно `0`.
* **Указатель текущего Слайда:** Порядковый номер Слайда из Сценария, на котором основывается Раздел (с Демо-объектом и Заметками которого работает лектор). После загрузки Сценария указатель равен `1`. При завершении записи Раздела по команде "перейти к следующему" автоматически инкрементируется, если Слайд не последний в Сценарии. Если Слайд последний, то запись следующего Раздела не начинается. При выборе произвольного Слайда для записи указатель получает номер Слайда в Сценарии.
* **Прогрессор лекции:** Кнопка перехода к записи следующего Раздела, основанного на следующем Слайде. 
  * *Если запись Лекции на паузе:* Нажатие начинает запись нового Раздела на основе текущего Слайда.
  * *Если идет запись Раздела K (основанного на Слайде L):* Нажатие мгновенно завершает запись Раздела K, сохраняет его в БД и без паузы начинает запись Раздела K+1 на основе следующего Слайда L+1.
* **Кнопка "Стоп":** Останавливает текущую запись и сохраняет Раздел в БД. Активна только во время записи. После нажатия номер текущего Слайда увеличивается на 1 (если это не финал Сценария).
* **Кнопка "Открыть содержание":** Вызывает выпадающий список с заголовками всех Слайдов Сценария. Выбор Позволяет вручную выбрать любой слайд для старта записи секции с него.
* **Кнопка "Открыть окно демо":** Открывает модальное или отдельное окно демонстрации, где отображается сам слайд и элементы управления им. По стандартам W3C браузеры блокируют автоматическое открытие всплывающих окон, поэтому окно открывается по клику пользователя.
* **Кнопка "Открыть окно заметок":** Открывает в отдельном окне шпаргалку (текст заметок) к текущему слайду для лектора.
* **Кнопка "Клон окна демо":** Создает дополнительное окно, дублирующее медиапоток из основного окна демонстраций. Предназначено для перетаскивания на второй монитор (для показа аудитории).
